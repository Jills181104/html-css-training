# SECTION 01 — WELCOME AND FIRST STEPS

## Front-End vs. Back-End

### Front-End

The **front-end** is the part of a website that runs in the browser and is visible to the user.

Main technologies:

- **HTML** → Structure/content
- **CSS** → Styling/presentation
- **JavaScript** → Behavior/interactivity

### Back-End

The **back-end** runs on the server and handles:

- Application logic
- Database operations
- Requests and responses
- APIs

Common back-end languages: **JavaScript/Node.js, Python, Java, PHP, C#**, etc.

---

## How a Website Works

The browser sends a request to the server, and the server sends back a response.

### Static Website

Files are sent to the browser mostly as they are.

### Dynamic Website

The server can generate/assemble content using application logic and databases.

---

## The 3 Front-End Languages

| Technology     | Purpose                    | Easy Way to Remember |
| -------------- | -------------------------- | -------------------- |
| **HTML**       | Content & structure        | Nouns                |
| **CSS**        | Appearance & presentation  | Adjectives           |
| **JavaScript** | Behavior & dynamic effects | Verbs                |

### HTML

Defines what is on the page.

### CSS

Defines how HTML looks.

### JavaScript

Defines what the page does.
